# To-do-app

Simple To-Do Web App

A new user can sign up with an email and password.
The system rejects sign-up if the email is already registered or is in an invalid format.
A registered user can log in with their email and password.
Only logged-in users can see the to-do pages. Others are sent to the login page.
A user can log out from any page.
A user can add a task with a title. The title is required.
A user sees only their own tasks.
A user can edit a task’s title.
A user can mark a task as completed or not completed.
A user can delete a task after confirming.
A user can filter tasks by All, Active, or Completed.
Tasks stay saved after logout or a page refresh.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
